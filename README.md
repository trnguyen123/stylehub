# StyleHub

**StyleHub** là một nền tảng thương mại điện tử thời trang hiện đại, giúp người dùng dễ dàng khám phá và mua sắm các sản phẩm như quần áo, giày dép và phụ kiện. Với giao diện thân thiện và tính năng tiện lợi, StyleHub mang đến trải nghiệm mua sắm trực tuyến mượt mà cho mọi người yêu thời trang.

## Tính năng chính

- Hiển thị danh sách sản phẩm theo danh mục
- Tìm kiếm sản phẩm theo tên
- Thêm sản phẩm vào giỏ hàng
- Đăng ký / Đăng nhập người dùng
- Thanh toán đơn hàng
- Giao diện thân thiện, responsive

## Công nghệ sử dụng

| Phần | Công nghệ |
|------|-----------|
| Frontend | React|
| Backend | Node.js, Express |
| Cơ sở dữ liệu | MySQL |
| Authentication | JSON Web Token (JWT), LocalStorage |
| API | RESTful APIs |

## Cách chạy dự án

### 1. Backend (Node.js + Express)

cd backend
npm install
npm start

### 2. Frontend (React)

cd frontend
npm install
npm start
